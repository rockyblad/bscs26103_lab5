# bscs26103 KeyWave

KeyWave is a keyboard selling website created as part of ICT Lab 5. The website allows users to explore different keyboard products, view their prices and check their availability. It also includes an About Us page with information about KeyWave and links to its social media pages.

The website was built using HTML for the structure, CSS for styling and JavaScript for interactive features. JavaScript was used to display a welcome message, show the current year, check product availability and provide form validation. A simple JavaScript chatbot was also included as part of the lab task.
